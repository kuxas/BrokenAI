自力で書いたコードはタイムアウトした.
→非常に大きな数字が入力されたとき、n/2だと処理しきれなかったため.
→今回の問題で考えるべきはnの正の約数のため最大値は√n
→√nまでをループ範囲にすればタイムアウトせず解ききることができた.

もう一つの原因として,宣言方法のミス
→今回は10^12までの数をあつかいたかったためintではオーバーフローする可能性がある
→よってlong longで宣言するべきだった.
    int main() {
    int n;
    cin >> n;

    int min = n - 1;
    
    for (int i = 1; i < n / 2; i++) {
        if (n % i == 0) {
        cnt = (i - 1) + (n / i - 1); // i,j方向の移動量
        if (cnt < min) {
            min = cnt;
        }
        }
    }

    cout << min << '\n';
    return 0;
    }
